# Ganguly's Notes Blog

This blog is intentionally static because the root project is a pure HTML, CSS, and JavaScript website.

## Add a future article

1. Copy `welcome-to-gangulys-notes.html` and rename it with a clear slug, for example `java-loops-practice.html`.
2. Update the title, meta description, canonical URL, Open Graph data, article dates, tags, and structured data.
3. Add the article entry to `articles.json`.
4. Add the article card to `blog/index.html`.
5. Add the article URL to `../sitemap.xml`.
6. Place original or replaceable article artwork in `../assets/blog/`.

## Future AI workflow

AI can generate article drafts from a structured brief containing title, audience, class level, topic, keywords, examples, diagrams needed, downloadable resources, and review notes. A human should verify syllabus alignment, code correctness, and source accuracy before publishing.
